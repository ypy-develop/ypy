# YPY for VS Code

The VS Code extension for YPY is not part of this release. What ships is the data VS Code reads without one:

- `ypy.html-data.json`: HTML Custom Data for the `ypy-*` attributes, `ypy-partial` and `ypy-on::<event>`. Generated by
  `ypy gen` from `src/attributes.json` and `src/attributes.d/`; do not edit it by hand.
- The JSON Schema of the configuration is `src/editors/schema/ypy.config.schema.json` (`dist/editors/schema/`).

How to install them, and how the table behind them works: <https://ypy.dev/docs/reference/editors>.

JetBrains editors read `dist/editors/jetbrains/ypy.web-types.json` (source: `src/editors/jetbrains/ypy.web-types.json`).
